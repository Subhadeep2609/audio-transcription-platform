# Audio Transcription Platform



A full-stack real-time audio processing platform featuring:



- Circular audio frequency visualizer

- Live streaming transcription

- Low-latency bi-directional streaming



## Tech Stack



### Frontend

- React

- TypeScript

- Web Audio API

- MediaStream API

- Canvas API



### Backend

- Spring Boot

- Spring WebFlux

- WebSockets / SSE

- Gemini Streaming API



### Deployment

- Frontend: Vercel

- Backend: Render
